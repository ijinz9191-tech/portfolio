Metric Contract Lab

  • Python 3.11+
  • SQLite
  • SQL
  • Read-only HTTP API
새로 구현한 내용
불변 Metric Contract, 원자적 이벤트 수집, Batch 재전송·중복 충돌 검사, 지연 이벤트의 stale 판정, 집계 버전과 SHA-256 lineage
검증 범위
2026-09-20 KST 로컬 실행 기록: 정상 집계, Transaction rollback·복구, 재시작, 잘못된 JSON Type, 실제 HTTP·CLI를 포함한 18개 테스트 통과. Python 소스 해시와 실행 결과를 함께 기록했습니다.

CAREEROPS

근거를 다음 결과로 연결하는 방식

CareerOps는 공고 분석부터 신규 프로젝트와 맞춤 문서, 접수 확인까지 연결하는 자동화 시스템을 구축하는 작업입니다. 기존 Harness가 범위와 권한을 관리하고 전문 Skill이 각 단계의 산출물을 담당합니다.

  1. 01

    Analyze

    공식 공고와 실제 경력 근거를 대조하고 해결할 문제를 정합니다.

  2. 02

    Build & Test

    공고별 프로젝트를 구현하고 정상·실패 경로를 검증합니다.

  3. 03

    Publish

    소스 버전과 공개 링크를 확인하고 Portfolio에 누적합니다.

  4. 04

    Apply & Verify

    맞춤 문서와 권한을 검사한 뒤 접수 증거로 완료를 판단합니다.

현재 공개 범위

이 사이트에는 Incident Replay Lab과 Metric Contract Lab의 코드·문서·로컬 검증 범위를 소개합니다. 위 흐름은 구축 목표이며, 전체 과정의 무개입 실행이나 신규 공고별 프로젝트·실제 접수 실적을 입증하는 표시가 아닙니다. 미측정 자동화 비율과 시간 절감률은 산출하지 않습니다.
