# 엔지니어링 포트폴리오 사이트

공개 정적 소개 페이지입니다. 브라우저 실행에는 외부 패키지가 필요하지 않습니다. `index.html`, `styles.css`, `fonts/PretendardVariable.woff2`, 글꼴 라이선스 `fonts/OFL.txt`만 게시합니다. API, 계정 연동, 지원자 자료, 쿠키, 양식과 외부 글꼴 요청은 없습니다.

## 디자인과 탐색

사용자가 지정한 `office` 프로젝트의 최신 디자인을 적용했습니다. 남색 사이드바, 밝은 배경, 보라색·민트색 강조, 둥근 카드와 Pretendard 글꼴을 사용합니다. 작은 화면에서는 메뉴가 하단으로 이동합니다. 32개 프로젝트의 설명·기존 소스 링크·검증 근거를 유지하고, 각 카드의 ‘구현·검증 상세 보기’를 키보드와 터치로 펼칠 수 있습니다.

글꼴은 `office`의 로컬 자산을 재사용하며 SIL Open Font License를 함께 배포합니다. 실행 중인 서비스나 측정하지 않은 성과를 표시하지 않습니다.

## 로컬 확인

저장소 루트에서 Node.js 24로 실행합니다.

```sh
node --test --test-isolation=none site/test.mjs
node site/serve.mjs
```

미리보기 주소는 http://127.0.0.1:4189 이며 로컬에서만 열립니다. Ctrl+C로 종료합니다. 미리보기는 위의 공개 자산만 제공하고 다른 경로는 `404`, 쓰기 요청은 `405`를 반환합니다. 자동 테스트는 내용, 링크·앵커, CSS·글꼴·라이선스, 헤더, 금지 경로와 쓰기 요청을 확인합니다. 시각 점검은 브라우저에서 데스크톱·태블릿·모바일 폭, 가로 넘침, 글꼴 로딩, 상세 펼치기와 키보드 탐색을 확인합니다.

## 저장 후 포맷팅

개발용 Prettier는 `package.json`과 잠금 파일에 `3.9.9`로 고정되어 있습니다. 개인 `prettier-source-formatting` 스킬의 `format-source.mjs --write -- <저장한 파일>`을 저장 직후 실행합니다. Markdown과 비밀 설정 파일은 해당 스킬의 대상에서 제외됩니다. 로컬에서 추가로 확인하려면 다음을 실행합니다.

```sh
npm ci --ignore-scripts
npm run format:check
```

## 게시

위 명령만으로 배포되지는 않습니다. 승인된 Pages 절차 또는 게시 브랜치로 정적 자산을 제공할 수 있습니다. 게시자는 저장소 Pages 설정, 자격 증명과 실제 비로그인 접근 주소를 확인해야 합니다. 저장소 전체나 실행 중 SQLite 파일을 게시하지 않습니다. `ai/sre` 앱은 별도 로컬 Node API가 필요하므로 온라인 데모가 아닌 소스 링크로 표시합니다.

## 사실성과 유지 관리

기존 장애 재현 실습을 새 공고 지원의 신규 작업으로 돌리지 않습니다. 새로 검증한 프로젝트는 사이트와 `ai/PROJECTS.md`에 추가하고 `ai/README.md`를 보존합니다. 공개 지원 건수와 측정하지 않은 자동화 지표는 넣지 않습니다. 사용자 목표를 바탕으로 AI가 사이트 파일을 작성했으며 사용자가 혼자 구현했다고 주장하지 않습니다.
