# 채용 준비 자동화 프로젝트

> **다양한 AI Skill을 활용해 프로젝트를 개발하고, 테스트로 검증한 뒤 GitHub에 Push하고, 최종적으로 Playwright를 활용해 실제 채용공고 지원까지 자동화한 시스템입니다.**

## 포트폴리오 구현과 실제 검증

32개 실습의 알고리즘·자료구조·복구 불변조건을 개선했습니다. 프로젝트별 복잡도와 반례 설명, 현재 소스 해시가 연결된 실행 결과는 [구현 깊이와 검증](quality/README.md)에서 확인할 수 있습니다. 공개 실습은 합성 데이터만 사용하며 개인 지원 정보와 분리되어 있습니다.

## 핵심 흐름

```text
다양한 AI Skill 활용
        ↓
요구사항 분석
        ↓
코드 작성 / 수정
        ↓
자동 테스트 및 검증
        ↓
실패 시 원인 분석 및 재수정
        ↓
검증 완료
        ↓
변경 사항 커밋
        ↓
GitHub 게시
        ↓
포트폴리오 최신화
        ↓
채용공고 탐색 및 분석
        ↓
기업별 지원 내용 구성
        ↓
Playwright 기반 채용 사이트 자동화
        ↓
지원 페이지 접근
        ↓
지원 정보 입력
        ↓
이력서 / 포트폴리오 첨부
        ↓
필수 항목 검증
        ↓
공고 지원
        ↓
지원 결과 기록
```

### 1. 다양한 Skill을 활용한 개발

요구사항을 분석하고 필요한 작업에 따라 여러 Skill을 선택적으로 활용합니다.

예를 들어 다음과 같은 역할을 분리할 수 있습니다.

- 요구사항 분석
- 구현 계획 수립
- 코드 작성
- 코드 리뷰
- 디버깅
- 테스트
- 결과 검증
- 문서화
- Git 작업
- 채용공고 분석

각 단계는 단순히 텍스트를 생성하는 것이 아니라 다음 작업으로 연결됩니다.

### 2. 코드 구현

분석된 요구사항과 계획을 기준으로 실제 프로젝트 코드를 작성하거나 수정합니다.

기존 프로젝트 구조와 기술 스택을 분석하고,
필요한 기능 구현 및 개선 작업을 수행합니다.

### 3. 테스트와 재검증

코드 작성 이후 바로 완료 처리하지 않습니다.

테스트를 수행해 실제 기능이 정상적으로 동작하는지 확인하고,
문제가 발생하면 원인을 분석한 뒤 수정과 재검증을 반복합니다.

```text
코드 구현
   ↓
테스트
   ↓
실패
   ↓
원인 분석
   ↓
코드 수정
   ↓
재검증
   ↓
통과
```

### 4. GitHub 게시

테스트를 통과한 변경사항만 Git에 반영합니다.

```text
테스트 통과
    ↓
변경사항 확인
    ↓
변경 사항 커밋
    ↓
GitHub 게시
```

이를 통해 GitHub에는 실제 검증이 완료된 작업 결과가 지속적으로 쌓이도록 구성합니다.

### 5. 포트폴리오 갱신

GitHub에 반영된 프로젝트 결과를 기준으로 포트폴리오도 최신 상태로 갱신합니다.

새로운 기능,
기술 스택,
문제 해결 과정,
테스트 결과 등을 포트폴리오에 반영합니다.

### 6. 브라우저를 활용한 채용공고 지원

개발과 GitHub 반영이 끝나면 채용 지원 단계로 연결됩니다.

채용 사이트의 실제 화면과 입력 상태를 확인하며 지원 작업을 진행합니다.

- 채용공고 페이지 접근
- 지원 페이지 이동
- 지원 폼 탐색
- 지원자 정보 입력
- 경력 및 프로젝트 정보 입력
- 자기소개서 입력
- 이력서 첨부
- 포트폴리오 첨부
- 체크박스 / 동의 항목 처리
- 필수 입력값 확인
- 제출 전 최종 검증
- 지원 진행
- 지원 결과 기록

```text
     ↓
[테스트]
     ↓
[원인 분석 / 재검증]
     ↓
[결과 검증]
     ↓
[변경 사항 커밋]
     ↓
[GitHub 게시]
     ↓
[포트폴리오 갱신]
     ↓
[채용 공고 분석]
     ↓
[지원 서류 작성]
     ↓
[브라우저 입력]
     ↓
[입사 지원]
     ↓
[접수 결과 기록]
```

## GitHub 소개 문구

> **다양한 AI Skill을 조합해 실제 코드를 작성하고 테스트로 검증한 뒤 GitHub에 Push하며, 이후 Playwright를 이용해 실제 채용공고 지원까지 연결한 End-to-End 자동화 프로젝트입니다.**

## 한 줄 소개

> **AI 스킬 → 코드 구현 → 테스트 → GitHub 게시 → 채용 사이트 지원**

## 강조 문구

> **다양한 Skill을 활용한 개발부터 테스트, GitHub Push, 그리고 Playwright를 통한 실제 채용공고 지원까지 하나의 자동화 흐름으로 연결했습니다.**

## 간단 소개

**여러 스킬을 활용한 코드 구현 → 테스트 → GitHub 게시 → 실제 채용 사이트 지원**
