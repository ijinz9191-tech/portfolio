# 공간 네트워크 근거 실습

가상의 이동 네트워크를 오프라인에서 검증합니다. 좌표 범위, 그래프 ID 중복, 존재하지 않는 간선 끝점, 경로 간선의 연결성과 간선별 직선거리 하한을 검사합니다. `stops`를 지정하면 출발지·경유지·도착지가 실제 간선 순서대로 나타나는지 확인해, 연결된 경로가 엉뚱한 목적지에 닿는 경우도 거부합니다. 기존 `edge_ids` 형식은 계속 사용할 수 있습니다. 정규화 입력의 SHA-256 해시가 출력과 예제를 연결하며 입력 행 순서를 바꾸어도 해시는 같습니다.

```powershell
conda run -p <compatible-environment-prefix> python -B -m unittest discover -s tests -v
conda run -p <compatible-environment-prefix> python -B audit.py samples/network.json
```

가상 지도 점과 경로를 사용해 AI 보조 도구로 만든 포트폴리오 실습입니다. 고용주·고객 위치 자료를 사용하거나 경로를 최적화하지 않습니다. 실제 지도 정확도 또는 과거 GIS 업무를 주장하지 않습니다.

## 구현 깊이와 검증

`audit`는 검증한 양의 거리 간선의 방향 인접 목록을 구성하고 이진 힙 Dijkstra로 출발지별 최단거리 근거를 계산합니다. 같은 출발지 경로는 계산을 공유합니다. 경로 길이는 `math.fsum`으로 합산하고, 실제 입력 경로와 출발·도착점 최단거리 하한의 차이를 별도로 표시합니다. V개 노드·E개 간선·서로 다른 출발지 A개에서 탐색 시간은 O(A(V+E) log(V+E)), 추가 공간 O(E+AV)입니다. 원래 입력 검증·경로 순회·정렬 비용이 더해집니다.

불변조건은 가상 양의 방향 그래프의 최단거리가 제출한 유효 경로 길이를 넘지 않는 것입니다. `tests/test_depth.py`는 평행 간선·순환이 있는 고정 난수 그래프를 Bellman-Ford 기준구현과 대조하고, 출발점으로 돌아오는 경로의 0 거리 하한을 검사합니다. 이 하한은 **필수 경유지 제약을 제외**한 출발·도착점 기준입니다. 우회 거리 표시가 실제 경로의 비효율이나 지도 정확도를 증명하지 않으며 경로 자체를 변경하지 않습니다.
