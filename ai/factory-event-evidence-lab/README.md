# 공장 이벤트 근거 실습

가상의 제조 인계 이벤트를 오프라인에서 검토합니다. 각 제조 단위가 지정된 작업장을 지날 때 `START`와 `COMPLETE`가 순서대로 있는지 확인합니다. 미완료 순서는 `EVIDENCE_GAP`으로 표시하고 작업장 건너뛰기, 중복 이벤트, 불가능한 순서, 모호한 시각은 거부합니다. 결과에 정규화 입력의 SHA-256 해시를 담아 같은 자료를 다시 검토할 수 있습니다.

```powershell
python ai/factory-event-evidence-lab/audit.py ai/factory-event-evidence-lab/samples/events.json
python -m unittest discover -s ai/factory-event-evidence-lab/tests -v
```

예제는 가상으로 만든 기록입니다. MES 연동이나 품질 판정, 특정 제조사에서 수행한 업무를 나타내지 않습니다. 이 검사는 제공된 로그의 정합성만 확인하며 물리적 공정의 실제 수행을 증명하지 않습니다.


## 구현 깊이와 검증

lot 상태 머신으로 인계를 검증하고 완료 구간의 정수 마이크로초를 산출한다. station 시작/완료 경계 정렬과 선형 스윕으로 동시 lot 최대 수를 계산하며 같은 시각 완료를 먼저 반영하는 반개구간 규칙을 사용한다.

- **시간·공간 복잡도:** 이벤트 n개: 정렬 O(n log n), 상태 전이/스윕 O(n), 공간 O(n).
- **불변조건:** lot 순서·증가 시각 유지, 미완료 구간의 시간·부하를 추정하지 않는다.
- **경계·기준 검증:** 순열 동일 결과, 정확한 마이크로초, 잘못된 station 타입, 중첩/맞닿은 경계 peak=2.
- **실행:** 프로젝트 폴더에서 `python -B -m unittest discover -s tests`.
- **한계:** 완료 관측이 있는 구간만 부하 대상이다. 설비 용량·MES 점유·생산 성과는 보장하지 않는다.

자료구조·상태 전이·불변조건을 실행 가능한 합성 실습으로 검증한다. 공인 프로그래머스 레벨, 측정하지 않은 성능 배율, 과거 회사 운영 성과를 뜻하지 않는다.
