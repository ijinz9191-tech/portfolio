# 답변 근거 추적 실습

업무 문서를 활용하는 AI 서비스에서 답변 문장이 어느 문서의 어느 구절을 근거로 삼았는지 확인하는 작은 실행 도구입니다. 모든 입력은 가상 자료이며 외부 모델이나 회사 시스템에 접속하지 않습니다.

## 확인하는 것

- 모든 주장에 인용이 있는지, 인용 대상 문서 ID가 실제 입력에 있는지 확인합니다.
- 인용 구절이 해당 문서에 존재하는지와 문서의 SHA-256 버전이 제출 당시와 같은지 검사합니다.
- 누락·중복·존재하지 않는 근거를 실패로 반환하고, 입력 전체의 해시를 결과에 기록합니다.

이 도구는 **문장과 인용의 추적 가능성만** 검사합니다. 인용이 주장에 의미적으로 충분한 근거인지, 문서 자체가 참인지는 판정하지 않습니다. 운영 환경에서는 담당자의 검토와 별도 사실 검증이 필요합니다.

## 실행

Conda 환경의 Python 3.11 이상에서 외부 패키지 없이 실행할 수 있습니다.

```powershell
python .\ai\grounded-answer-evidence-lab\audit.py .\ai\grounded-answer-evidence-lab\samples\answer.json
python -m unittest discover -s .\ai\grounded-answer-evidence-lab\tests -p 'test_*.py'
```

정상 예시는 종료 코드 `0`, 근거가 추적되지 않는 주장은 `1`, 입력 형식 오류는 `2`를 반환합니다. `source_sha256`은 원문 텍스트 UTF-8 바이트의 SHA-256입니다.

## 공개 범위

이 코드는 지원 공고를 분석하며 AI 보조로 만든 학습용 구현입니다. 실제 고객 데이터, 업무 문서, NHN 내부 시스템, 운영 RAG/에이전트 구축 경험을 뜻하지 않습니다. 기존 [AI 에이전트 평가 제어 실습](../agent-eval-control-plane/README.md)의 사실별 근거 연결 검사를 보완하는 독립적인 문서 내용 검사입니다.

## 구현 깊이와 검증

`audit`는 문서별 원문 버전 해시와 공백 정규화 본문을 한 번 계산한 인덱스로 여러 인용을 검사합니다. 인용의 정규화 구절도 한 번 계산해 중복 감지와 존재 검사를 공유합니다. 전체 문서 길이 D에 대해 전처리 시간·공간 O(D), 인용 C개의 문자열 검색은 구절·본문 길이에 따라 추가되며 보수적인 단순 검색 상한은 O(Σ 본문길이×구절길이)입니다. 입력 전체 해시를 위한 직렬화 공간은 별도입니다.

불변조건은 원문 해시는 정규화 전 UTF-8 본문으로 계산하고, 공백 차이만 있는 같은 인용도 중복으로 처리하는 것입니다. `tests/test_depth.py`는 1,000개 주장에 재사용되는 문서가 한 번만 해시되는지 확인하고, 줄바꿈·연속 공백의 중복 인용을 검사합니다. 이 인덱스는 호출 내부에만 존재하므로 다음 호출에서 문서 버전이 바뀌면 다시 계산합니다. 인용 존재는 문장의 의미적 지지나 사실의 진위를 보증하지 않습니다.
