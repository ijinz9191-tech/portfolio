# 공간 데이터 배포 영향 검사 실습

지도 데이터가 바뀌었을 때 변경된 구간만 세는 것으로는 어떤 경로가 영향을 받는지 알기 어렵습니다. 이 오프라인 도구는 배포 전후의 구간 버전과 경로가 참조하는 구간을 대조하고, 영향을 받는 경로의 담당자 확인과 되돌릴 기준 버전을 검사합니다. 한 경로만 바뀌면 다른 경로의 확인을 요구하지 않습니다.

```powershell
conda run -p <호환-환경-경로> python -B -m unittest discover -s tests -v
conda run -p <호환-환경-경로> python -B audit.py samples/change.json
```

명세에는 `baseline`, `candidate`, `acknowledgements`가 필요합니다. 각 지도 버전에는 `segments`와 `routes`를 넣습니다. 구간의 `geometry_revision`은 입력자가 제공한 버전 식별자이며 이 도구가 실제 지형을 계산하거나 버전 식별자의 진위를 검증하지는 않습니다. 기존 경로가 참조하는 구간의 버전이나 경로 순서가 바뀌거나 새 경로가 추가되면 영향 경로로 분류합니다. 해당 경로마다 검토자와 이전 지도 버전을 가리키는 `rollback_version`이 있어야 `READY_FOR_HUMAN_REVIEW`를 반환합니다. 확인이 빠졌으면 `BLOCKED`와 누락 목록을 반환하고 명령행 종료 코드는 1입니다. 입력 자체가 잘못되면 종료 코드는 2입니다.

입력 행의 순서와 무관한 SHA-256 근거 ID를 남깁니다. 경로 내부의 구간 순서에는 의미가 있으므로 이를 바꾸면 별도 변경으로 취급합니다. 기존 경로 삭제는 별도의 은퇴 검토 절차가 필요해 거부합니다.

## 한계와 출처

합성 지도 명세만 다룹니다. 실제 지리 좌표, 실시간 경로 탐색, 지도 정확도, 운영 배포 승인을 검증하지 않습니다. AI 보조 도구로 새로 구현한 포트폴리오 실습이며 지원자의 과거 GIS 실무 경력을 뜻하지 않습니다. 기존 [공간 네트워크 근거 실습](../spatial-network-evidence-lab/README.md)은 단일 지도 안의 경로 연결과 거리 하한을 검사하고, 이 도구는 두 지도 버전 사이의 경로 영향과 검토 누락을 검사합니다.

## 구현 깊이와 검증

이전·새 명세의 세그먼트→경로 역색인을 만든 뒤 변경된 세그먼트가 참조된 경로를 합집합으로 계산합니다. 이전 명세도 포함하므로 새 명세에서 제거된 구간의 기존 영향이 사라지지 않습니다. 경로 순서 변경과 신규 경로는 별도 비교로 포착합니다. 세그먼트 S개·전체 경로 참조 L개·영향 참조 I개에서 시간 O(S+L+I), 인덱스 공간 O(S+L)이며 출력 정렬·해시 직렬화 비용은 별도입니다.

불변조건은 어느 쪽 명세에서든 변경 구간을 참조한 기존 경로가 누락되지 않고, 확인되지 않은 영향 경로가 있으면 차단하는 것입니다. `tests/test_depth.py`는 200개 경로의 고정 난수 명세에 대해 전체 경로 스캔 기준구현과 결과를 대조합니다. 실제 기하 형상·방향 연결·배포 권한은 검사하지 않으며 버전 식별자는 입력자가 제공한 값입니다.
